# Portfolio & Work Samples (Garrett M. Harper)

Live site: [https://garrett-m-harper.github.io/](https://garrett-m-harper.github.io/)

Static HTML, CSS, and vanilla JavaScript portfolio site for Dark Desert Media. Focuses on formula-driven Excel operations workbooks, technical proofreading and SOP redlining, relational record-keeping, and modular Python/Godot software utilities.

## Contents

- `index.html`, `assets/css/style.css`, `assets/js/main.js`: Static site and client-side discipline filtering plus the interactive `SOP-OPS-042` redline demo.
- `samples/`: Downloadable Excel `.xlsx` workbooks (`Vendor_COI_W9_Compliance_Tracker_Sample.xlsx`, `Master_SKU_Inventory_Reconciliation_Sample.xlsx`) generated via `build_excel_samples.py`.
- `data/`: Structured project metadata (`projects.json`, `projects.js`).
- `.github/workflows/deploy.yml`: Automated quality checks and GitHub Pages deployment workflow.
